# Magic Academy Math Game

A mobile-friendly React + Tailwind interactive game for kids (ages 5–8) with step-by-step math spells:

- Level 1: Multiply by 11 (neighbor addition)
- Level 2: Multiply by 5 (half + odd bonus)
- Level 3: Multiply by 9 (complement to 9)

## Local development

```bash
npm install
npm run dev
```

## Cloudflare Pages deployment

Use these settings:

- Framework preset: **Vite**
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `magic-academy-game`
